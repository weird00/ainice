# 插件中心（Plugin Hub）

> 运行在 AInice 设备上的插件管理器：在一处配置多个插件库，集中查看、安装与升级设备上的其它插件。

## 简介

**插件中心**管理设备上已安装的插件。你只需要把插件的「库地址」填进去，它就会读取每个库的 `index.json`，汇总出**可安装**与**可升级**的插件，并允许直接在本页面完成安装与升级；同时它在后台周期性检查更新，发现新版本会在页面顶部给出提示。

插件中心自身也托管在本插件库中，因此可以自我更新。

## 功能特性

- **多插件库**：可添加任意多个库地址（上限 16 个），每个库独立选择加速镜像。
- **一次读整库**：每个库只读一次 `index.json`，即可拿到该库全部插件及其版本。
- **分区页签**：可更新 / 已安装插件 / 可安装 / 插件库 / 信息，各页签职责单一。
- **后台自动检查**：插件启动 **10 秒**后首检，之后每 **30 分钟**自动重跑一次，结果常驻进程内。
- **手动检查**：「可更新」页签内的「检查更新」按钮与顶部提示条的「重新检查」都可随时触发。
- **页面内安装 / 升级**：下载 → SHA256 校验 → 导入，全程无需离开页面。
- **加速镜像**：`自动（GitHub 走 jsDelivr）/ 强制 jsDelivr / 强制 ghproxy / 直连`。
- **运行日志**：内置日志查看，便于排查拉库与升级失败。
- **中英双语**：跟随平台语言切换，文案原位更新。

## 页面说明

| 页签 | 作用 |
| --- | --- |
| **可更新** | 列出可升级的插件，展示「当前版本 → 远端版本」与更新说明；底部可手动「检查更新」。 |
| **已安装插件** | 列出设备 `/plugins` 下扫描到的插件，两列平铺；支持「全部检查更新」与「重新读取」。 |
| **可安装** | 列出插件库里**尚未安装**的条目，可一键安装；异常条目会单独计数提示。 |
| **插件库** | 增删插件库地址、选择加速镜像并保存。 |
| **信息** | 展示上次检查时间与运行日志。 |

## 安装

**方式一：从库安装（推荐）**

在主控制台或用插件中心自身，把本库地址加入插件库后，在「可安装」里安装 `plugin-hub`。

**方式二：手动上传**

下载 [plugin-hub.plugin](./plugin-hub.plugin) 后，通过主控制台的插件页面直接导入安装。

## 使用

1. 打开「插件库」页签；
2. 点击「添加插件库」，填入库地址（例如 `https://gitee.com/hg-jason/ainice/raw/main`）；
3. 按需选择加速镜像，点击「保存插件库」；
4. 切到「可安装」查看库里尚未安装的插件并安装，切到「可更新」查看可升级的插件并升级；
5. 若检测到更新，页面顶部会出现更新提示条，可直接「查看」或「重新检查」。

### 库地址怎么写

- **目录 / 仓库地址**：先读 `<库>/index.json`，取不到再退回 `<库>/upgrade.json`（兼容「一个仓库一个插件」的老库）。
- **JSON 文件直链**：地址以 `.json` 结尾时只读它自己。
- 库地址**不能是 `.plugin` 包地址**，包地址会被忽略。

## 插件库格式（`index.json`）

一个插件库就是一个可匿名访问的地址，里面放一份 `index.json` 和各插件的 `.plugin` 包：

```text
ainice/
├── index.json
├── plugin-hub.plugin
├── presence-notify.plugin
└── ha-webhook.plugin
```

`index.json` 支持 `{"plugins": [...]}` 或直接数组：

```json
{
  "plugins": [
    {
      "id": "plugin-hub",
      "version": "1.6.0",
      "package_url": "https://gitee.com/hg-jason/ainice/raw/main/plugin-hub.plugin",
      "sha256": "包的 SHA256（小写十六进制）",
      "name": { "zh": "插件中心", "en": "Plugin Hub" },
      "description": { "zh": "插件用途说明。", "en": "Plugin purpose." },
      "change_log": ["本次新增了什么。", "本次修复了什么。"]
    }
  ]
}
```

| 字段 | 必需 | 作用 |
| --- | --- | --- |
| `id` | 是 | 唯一标识，也是去重键；无 `id` 的条目会被跳过 |
| `version` | 是 | 三段数字 `N.N.N`，与已装版本比较决定状态 |
| `package_url` | 是 | `.plugin` 包直链，用于安装 / 升级 |
| `sha256` | 是 | 包校验值，升级时强制校验 |
| `name` / `description` | 否 | `{zh, en}`，在「可安装」列表里显示 |
| `change_log` | 否 | 字符串数组，作为更新说明展示 |

**状态判定**：

- 设备上没装 → `library`（显示「安装」）；
- `远端版本 > 本地版本` → `update`（显示「升级」）；
- `远端版本 <= 本地版本` → `current`（显示「已是最新」）；
- 任一侧版本不是三段数字，或缺 `package_url` / `sha256` → `error`。

**更新源优先级**：手动覆盖 > 插件库索引 > 插件自身 `plugin.json` 的 `upgrade_url`。只要插件被某个库收录，就使用库里的元数据。

> 想了解发布与升级的完整操作（打包、算 SHA256、更新索引、常见报错），见《插件远程更新说明》。

## 工作原理

插件中心由 Python 后端进程与前端页面两部分组成，两者通过平台 Bridge 通信：

| Bridge 方法 | 说明 |
| --- | --- |
| `config.get` | 读取插件库配置（`sources`：库地址 + 镜像）与可选镜像列表 |
| `config.save` | 保存插件库配置 |
| `plugins.list` | 扫描 `/plugins` 已装插件，并返回库索引的合并视图 |
| `update.check` | 对指定插件逐个检查远端版本 |
| `updates.summary` | 读取后台自动检查的缓存结果（页面只读，不触发网络） |
| `updates.refresh` | 触发后端在后台立刻重跑一次检查 |
| `package.fetch` | 下载 `.plugin` 包并做 SHA256 校验，返回 base64 |
| `log.get` | 读取运行日志 |

安装 / 升级由前端拿到包内容后，携带 CSRF Token 调用平台接口 `POST /api/plugins/import` 完成。

## 目录结构

```text
plugin-hub/
├── plugin.json        # 插件声明：id / version / name / description
├── plugin-hub.app     # 后端进程入口（Python）
├── build.sh           # 打包脚本
└── www/
    ├── index.html     # 页面骨架：顶部提示条 + 五个页签面板
    └── assets/
        ├── app.js     # 页面逻辑：拉库、检查、安装/升级、日志
        ├── app.css    # 样式
        └── host.js    # 与平台交互（导入插件包）
```

## 构建与打包

```sh
cd plugin-hub
./build.sh
```

脚本会把 `plugin.json`、`plugin-hub.app`、`www/` 打成 `plugin-hub.plugin`，并按裸 tar 头逐条校验，确保包内只有普通文件与目录（不含 symlink、PAX 扩展头等平台不支持的内容）。

> macOS 下必须保留 `tar --format=gnutar` 且 `COPYFILE_DISABLE=1`，否则包内会混入 `PaxHeader/*` 与 `._*`，上传时被判为「包含不支持的文件」。

## 限制与技术要点

- **单次 Bridge 调用 15 秒绝对截止**：页面按「一次一个插件」串行检查，避免撑爆预算。
- **体积上限**：安装包 ≤ **512 KiB**（整包 base64 后走一次 Bridge 响应），元数据 JSON ≤ **256 KiB**。
- **索引缓存**：库索引在内存中缓存 **120 秒**，避免重复拉取。
- **设备网络**：`raw.githubusercontent.com` 不可达，默认镜像「自动」会把 GitHub 形态地址改写成 jsDelivr；Gitee 等非 GitHub 地址按原样请求。
- **版本号**：只支持三段数字 `N.N.N`，且远端必须严格更高才会提示升级。
- **数据落盘**：插件只能写 `/data/plugins/plugin-hub`（日志 `hub.log`），`/plugins` 是平台保留的只读目录。
